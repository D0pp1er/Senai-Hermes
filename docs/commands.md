# Command and API reference

The current complete usage, smoke-test API guide and architecture are consolidated in [README.md](../README.md).

Use senai --help and command-specific --help for exact parser options.

Basic registry UX: senai skill list, import PATH_OR_WORKFLOW, use NAME, show NAME, export obsidian. Advanced lifecycle: senai skills --help. Selected project skills apply to normal coding requests; --registry-skill overrides a request and native --skill remains separate. See README.md and senai/skills/README.md.
