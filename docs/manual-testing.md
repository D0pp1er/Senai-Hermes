# Manual acceptance: all features

Start with the [all-feature demonstration guide](all-features-demonstration.md).
It replaces the earlier core-only checklist with isolated setup, exact examples,
expected results and evidence for the complete harness.

Use the [134-case fillable CSV](all-features-checklist.csv) to record Pass, Fail or
Not run, actual results and artifact/report paths. The guide maps case IDs to sections.

For the deeper skills lifecycle and Obsidian procedures, follow the
[skills demonstration guide](skills-demonstration.md). Its 48 cases are also included
in the combined CSV; the separate [skills CSV](skills-demo-checklist.csv) remains available.

Run live checks only with your own disposable project/test bot. Keep credentials
outside logs/Git and record live results separately from offline fixtures. These guides
do not themselves constitute evidence that a manual check passed.
