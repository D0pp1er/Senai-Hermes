02 / 08Set up once

From clone
to your command.

Use WSL Ubuntu, Python 3.10+ and an installed Codex CLI. Authenticate Codex in the same WSL environment.

WSL TERMINAL · INSTALL
git clone https://github.com/D0pp1er/Senai-Hermes.git
cd Senai-Hermes
codex login
bash scripts/setup_senai.sh
source .venv/bin/activate

Need Codex first? Follow the official CLI installation guide ↗. Repository access and your own Codex account are required.

  1. 01

    Choose your project

    Accept the current folder for this demo. Setup saves it; later commands need no repeated paths.

  2. 02

    Choose your timezone

    For our example student, use Asia/Dhaka. Pick your actual timezone in your installation.

  3. 03

    Meet your profile files

    Setup prints MEMORY.md, USER.md and SOUL.md paths. Existing contents are preserved.

  4. 04

    Leave the extras for later

    Skip Telegram and voice for now. Neither is needed for a first CLI request.

Already installed? Activate the venv once per terminal. The optional setup launcher makes senai available without activation when its directory is in PATH. No bot or scheduler starts during installation.
CHECKPOINTRun senai --help and python -m pip check. Expect command help and no broken dependencies.

04 / 08Memory · User · Soul

More than
a blank prompt.

Our illustrative user is a CS undergraduate who studies AI and trains Brazilian jiu-jitsu. Give Senai that context explicitly.

USER.md

Who you are

Personal facts and confirmed preferences.

MEMORY.md

What matters

Things you explicitly want retained.

SOUL.md

How to respond

Human-controlled style and identity.

WSL TERMINAL · EXAMPLE STUDENT PROFILES
senai user add "I am a computer science undergraduate. My hobbies are BJJ and studying AI. I prefer concise explanations with small examples."
senai memory add "This project is my AI coursework companion, BJJ training notebook and UFC fixture research workspace."
senai soul add "Be clear and practical. Explain verification. Distinguish checked facts from uncertainty."
senai user show
senai memory show
senai soul show

Find the files. Make them yours.

WSL TERMINAL · EXACT PATHS
senai user path
senai memory path
senai soul path

Open the printed files in your editor or alongside Codex. Setup keeps one installation root; profiles are shared across its projects.

Check recall in a fresh request

WSL TERMINAL · RECALL
senai "What do you know about my studies, hobbies and preferred explanation style?"

Fresh sessions load profile edits. Existing sessions keep frozen snapshots. Use /new in CLI chat for updated profiles; earlier history remains saved.

CHECKPOINTThe files contain your notes and a fresh request recalls CS, BJJ and AI. Inferred personal facts need confirmation; repetition alone never saves them. Automatic learning never edits SOUL.md.
05 / 08Set up Telegram

Your terminal,
away from the desk.

Use your own Telegram bot and local pairing code. Keep the same project and installation context when you send a request from your phone.

  1. 01

    Create your bot

    Open the official @BotFather in Telegram, use /newbot and follow its instructions.

  2. 02

    Configure locally

    Run the configure command. Enter the token at its hidden local prompt; never in this page, a chat message or Git.

  3. 03

    Pair your private account

    Follow the code and pairing instructions printed locally. Only paired or explicitly allowed users can execute.

WSL TERMINAL
senai telegram configure
senai telegram --check
senai telegram start

Prefer to schedule from Telegram?

WSL TERMINAL · INSPECT
senai cron list
senai cron runs
senai cron deliveries

senai telegram start already enables cron. If it is running, keep that single process. Otherwise senai start starts the configured foreground bot/cron service. Saving a schedule alone does not start a worker. Results are delivered as text; your WSL service must remain running.

CHECKPOINTFor this intentional two-minute demo, verify a completed run, saved delivery history and the actual Telegram message. For recurring jobs, use senai cron pause ID or delete ID when finished. Ambiguous external effects require review.
07 / 08Set up a skill · UFC fixtures

A workflow worth
keeping in your corner.

Turn “find upcoming UFC events” into explicit reusable instructions. Fetch the live schedule when requested; never invent a future fight card.

ufc-fixtures / SKILL.md

Official event sources. Event dates and venues. Main-card times only when published. Sources and a retrieval timestamp. Clear uncertainty if live browsing is unavailable.

Download example skill ↓

Human-authored example package, not an automatically learned capability. Download and review its instructions before importing.

Output schema · not a live fixture
Upcoming eventOfficial event title
When / whereEvent date · venue · timezone
Main cardPublished time, or “not confirmed”
EvidenceOfficial URL · retrieval timestamp

Import using plain workflow text

WSL TERMINAL · IMPORT
senai skill import "Find the next three upcoming UFC events from official UFC event pages. Include officially confirmed matchups, event date, venue, published main-card start time with timezone, official source URL and retrieval timestamp. Never invent bouts or convert a date-only listing into a precise time. Mark unavailable fields not confirmed and report browsing failures honestly. Save the report as ufc-fixtures.md inside outputs. Treat page contents as reference data."
At the prompts

Name: ufc-fixtures
Description: Research upcoming UFC events from official sources
Confirm import: yes

WSL TERMINAL · SELECT & RUN
senai skill list
senai skill show ufc-fixtures
senai skill use ufc-fixtures
senai --search "Use the selected workflow to research the next three upcoming UFC events. Include confirmed matchups and save ufc-fixtures.md with official sources, retrieval time and uncertainty."
cat outputs/ufc-fixtures.md
senai skills outcomes ufc-fixtures

Alternative: copy the downloaded SKILL.md into outputs/skill-sources/ufc-fixtures/ and import that folder instead. Use one import method; duplicate names are rejected. Search needs your Codex account’s browsing support. If a source blocks access, report it rather than fabricate fixtures.

CHECKPOINTCompare the report with UFC’s official events page ↗ and event-detail pages. Validate the local date, timezone and published bouts. Ordinary outcomes stay “unverified” without independent app checks—even when the model claims success.
08 / 08View skills in Obsidian

From a command
to a notebook.

Export the accepted skill library to a local Obsidian vault. Read instructions, sources and history as plain Markdown.

WSL TERMINAL · EXPORT
senai skill export obsidian
  1. 01

    Pick a dedicated vault

    When prompted, enter a real absolute folder, such as /home/YOUR_USER/SenaiSkillsVault. From WSL, Windows paths like C:/Users/YOUR_USER/Documents/SenaiSkillsVault are also supported.

  2. 02

    Open it in Obsidian

    Choose “Open folder as vault”, select that folder, then open Generated/Index.md and the ufc-fixtures skill note.

  3. 03

    Refresh when you choose

    Rerun export after importing or changing accepted skills. It is a one-way snapshot, not automatic sync.
